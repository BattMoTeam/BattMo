=================
How to contribute
=================

Bugs and enhancements
---------------------

If you find a bug in BattMo, please report it as an issue on
`issues <https://github.com/BattMoTeam/BattMo/issues>`_. The same holds for
suggestions for enhancements. It is much appreciated.

Pull requests
-------------

To contribute code to BattMo, create a pull request at `pull requests <https://github.com/BattMoTeam/BattMo/pulls>`_.

Contact email
-------------

You're most welcome to contact the developers at battmo@sintef.no if you have questions.
